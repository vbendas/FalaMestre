## Overview

Fala Mestre! operates on a free-to-play model with multiple non-aggressive revenue streams. The core philosophy: the game should be fully enjoyable without spending money.

> [!important] Core Principle
> Free players should compete fairly. Premium accelerates, not dominates.

## Fan Token Revenue

### Attribution Model

```
User Journey:
1. Plays Fala Mestre! (free)
2. Earns Socios Points
3. Converts points to voucher (10,000 points = 1 voucher)
4. Redeems voucher for real fan token
5. (Optional) Purchases more tokens on Socios.com

Revenue Attribution:
- Voucher redemption: $0 direct cost to user
- First token purchase: 10% commission to Fala Mestre!
- Lifetime token purchases: 5% ongoing attribution
```

## Advertising

### Ad Strategy

> [!warning] Ad Philosophy
> Ads should never interrupt gameplay. Only optional rewarded ads.

### Ad Types

| Ad Type | Trigger | Reward | Frequency |
|---------|---------|--------|-----------|
| **Rewarded Video** | User-initiated | +50 points | Max 5/day |
| **Rewarded Video** | After loss | +25 points + morale boost | After losses only |
| **Interstitial** | Session end | None | Max 2/session (free users) |
| **Banner** | Menu screens | None | Free users only |

### Ad Revenue Projections

```
Assumptions:
- 60% of users are free (ad-eligible)
- Average 2 rewarded ads/day per free user
- Average 1 interstitial/day per free user
- eCPM (rewarded): $15
- eCPM (interstitial): $5
- eCPM (banner): $2

Monthly (10,000 MAU):
- Free users: 6,000
- Rewarded impressions: 360,000
- Interstitial impressions: 180,000
- Banner impressions: 1,800,000

Revenue:
- Rewarded: $5,400
- Interstitial: $900
- Banner: $3,600
Total: ~$10,000/month at 10K MAU
```

## Free-to-Play Balance

### Fair Progression

```
Time to Earn (F2P vs Premium):

First Fan Token Voucher (10,000 points):
- F2P: ~40 hours of gameplay
- Premium (2x): ~20 hours of gameplay

Top League Position:
- F2P: Achievable with skill
- Premium: Slightly faster, not easier

Best Players:
- F2P: Earn through gameplay
- Premium: Access same players, just faster
```

### Anti-Pay-to-Win Measures

1. **No stat boosts for purchase**
   - Cannot buy better player ratings
   - Cannot buy match advantages

2. **PvP balancing**
   - Matchmaking by team strength
   - Premium perks disabled in ranked PvP

3. **Transparent economy**
   - All point values clearly shown
   - No hidden advantages

4. **Skill rewards**
   - Better players earn more
   - Strategy beats spending

## Monetization Funnel

### Conversion Path

```
Day 1: First Session
├── Play free
├── Win matches
├── See points accumulate
└── Hook: "X more points to voucher!"

Day 2-7: Engagement
├── Daily login streaks
├── Tournament entry
├── First ad offer (post-loss)
└── Soft prompt: "Go PRO for 2x points"

Day 8-14: Consideration
├── Hit first friction (energy limit)
├── See premium features
├── Time-limited offer shown
└── 30% convert to first purchase

Day 15-30: Conversion
├── Premium trial offer ($0.99 first month)
├── Show value calculator
├── Social proof (friends on PRO)
└── Target: 10% to subscription
```

### Offer Timing

| Trigger | Offer | Discount |
|---------|-------|----------|
| First loss | Rewarded ad for morale | - |
| 3-day streak | PRO trial | 50% first month |
| First voucher earned | Points bundle | 20% off |
| Week 2 | Premium showcase | Full price |
| Day 30 | Annual subscription | 40% off |
| Churning user | Win-back offer | 60% off |
